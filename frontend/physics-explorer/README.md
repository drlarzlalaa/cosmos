# physics-explorer

Part of [`frontend`](../README.md) in the COSMOS platform.

**Status:** implemented (alongside `engines/physics-engine/gravity`,
early and out of strict roadmap order).

A form for `engines/physics-engine/gravity`'s four calculations
(force, escape velocity, orbital period, potential energy), built from
`GET /api/engines/gravity`'s listing so new calculations show up here
automatically. No sign-in required - these are deterministic, public
physics calculations, not user data.
